===========================
Django 1.4.44 release notes
===========================

*October 4, 2022*

Django 1.4.44 fixes a regression in 1.4.43.

Bugfixes
========

* Fixed a regression in Django 1.4.43 where saving ``FileField`` would raise a
  ``SuspiciousFileOperation`` even when a custom
  :attr:`~django.db.models.FileField.upload_to` returns a valid file path
