===========================
Django 1.8.26 release notes
===========================

*April 13, 2021*

Django 1.8.26 fixes a security issue with severity "low" in 1.8.25.

CVE-2021-28658: Potential directory-traversal via uploaded files
================================================================

``MultiPartParser`` allowed directory-traversal via uploaded files with
suitably crafted file names.

Built-in upload handlers were not affected by this vulnerability.

Fix was backported from git, https://github.com/django/django/commit/6d61860b22875f358fac83d903dc629897934815

CVE-2021-23336: Web cache poisoning via ``django.utils.http.limited_parse_qsl()``
=================================================================================

Django contains a copy of :func:`urllib.parse.parse_qsl` which was added to
backport some security fixes. A further security fix has been issued recently
such that ``parse_qsl()`` no longer allows using ``;`` as a query parameter
separator by default. Django now includes this fix. See :bpo:`42967` for
further details.

Fix was backported from git, https://github.com/django/django/commit/fd6b6afd5959b638c62dbf4839ccff97e7f7dfda
